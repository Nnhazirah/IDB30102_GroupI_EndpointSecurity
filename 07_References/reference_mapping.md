# Reference Mapping

The following references support the data collection and proposed evaluation aspects of the research.

## Data Collection and Behavioural Features

- Abdelwahed, A., Medani, K., & Guirguis, M. (2023) - Supports behavioural ransomware analysis through system API interception.
- Ahmed, R., Al-Dujaili, A., & O'Reilly, U. M. (2026) - Supports sliding window feature extraction for ransomware identification on Windows endpoints.
- Lee, K., & Lee, S. (2022) - Supports combining file I/O and entropy metrics for early ransomware detection.
- Ramamoorthi, S., Govindarajan, M., & Sundaram, P. (2026) - Supports endpoint telemetry and Sysmon monitoring.

## Machine Learning and Evaluation

- Elsersy, M., Hassan, N., & Mostafa, A. (2024) - Supports Random Forest-based ransomware classification on Windows endpoints.
- Muppidi, R. R., & Sureshkumar, V. (2025) - Supports the use of XGBoost for endpoint threat and ransomware detection.
- Zirari, M., Benabbou, A., & Boulaalam, A. (2025) - Supports SVM-based endpoint behavioural classification.
- Surya, K., & Sivakumar, R. (2024) - Supports ensemble voting approaches for endpoint security and threat mitigation.

These references are used to support the proposed data collection features, machine learning models and evaluation approach.
